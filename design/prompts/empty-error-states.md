# Empty & error states — Editorial Paper

Cross-cutting states: empty workspace, empty discover feed, failed ingest, 404.

> A desktop browser mockup, four-quadrant grid, of Pepiros empty and error states, Editorial Paper direction. Each quadrant: dark warm-charcoal chrome, a centered small muted-line illustration (an open book, a blank pillar outline, a torn-corner page), a short serif message line, one calm text-link action, small-caps serif micro-label. No red alert colors, no exclamation icons — errors read as quiet and honest, in the same register as the "quote located, not verified" language rule. Generous whitespace, soft ambient lighting, 16:9.

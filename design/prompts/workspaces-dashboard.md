# Workspaces dashboard — Editorial Paper

New surface: authenticated landing page listing a user's workspaces.

Dark warm-charcoal chrome, a grid of warm paper-textured workspace cards (#FAF8F4, subtle grain), each showing a serif workspace name, a small mono paper-count, and a muted pillar-color accent stripe at the top edge only.

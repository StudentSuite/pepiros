# Auth (sign in / sign up) — Editorial Paper

Platform-vision surface, per `docs/PLAN-V1.md §22`. Not built as working code today — design direction only.

> A desktop browser mockup of the Pepiros sign-in screen, Editorial Paper direction. A centered warm paper-textured card (#FAF8F4, subtle grain) on a dark warm-charcoal background, generous margins. Small-caps serif label above the form ("sign in to pepiros"), serif-adjacent grotesque input fields with soft paper-sunk backgrounds, a single warm ink-toned primary button. No SaaS gradient, no heavy drop shadow, calm and unhurried, generous whitespace, soft ambient lighting, 16:9.

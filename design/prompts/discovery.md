# Discovery / public feed: Editorial Paper

Platform-vision surface, per `docs/PLAN-V1.md §22`. Not built as working code today, design direction only.

> A desktop browser mockup of the Pepiros public paper discovery feed, Editorial Paper direction. A warm paper-textured content column, like a digital magazine index, listing paper cards: serif title, a muted-pillar-color topic tag, small metadata line (author, date, discussion count) in small-caps serif micro-type. Dark warm-charcoal chrome, generous vertical rhythm between cards, soft muted accents, no harsh borders, calm editorial layout, 16:9.

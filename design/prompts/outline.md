# Outline (a11y tree view): Editorial Paper

Existing app surface, consistency pass against the Editorial Paper lock.

> A desktop browser mockup of the Pepiros outline view, Editorial Paper direction. Dark warm-charcoal chrome frames a nested, indented serif text tree (paper > pillar > leaf), muted pillar-color dots marking each node's kind, small-caps serif node-type labels, generous line height between rows. No graph, purely a calm reading-order list. Soft ambient lighting, generous whitespace, 16:9.

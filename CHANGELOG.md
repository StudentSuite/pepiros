# Changelog

All notable changes to this project are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/) once it has a real release — pre-1.0, expect breaking changes without notice.

## [Unreleased]

Still stubbed (see the `TODO` comment at the top of each file): OCR fallback for scanned/image-only PDFs (`scripts/ocr_fallback.py` -- ingest now fails those loudly instead of silently, but doesn't recover text from one yet), `scripts/seed.ts`, 1 of the ~22 node generators (`concept_links` -- already solved a different way, see below), 2 of 6 synthesis node types (Dataset Overlap, Open Questions -- need signals nothing extracts yet), session refresh (revocation is real; silent renewal isn't), the MCP package's npm publish, and `evals/`/drop-rate measurement.

### Added since [0.1.1] (real backend, accounts, and synthesis)

Real Postgres now backs everything the [0.1.1] entry below still described as reading only the bundled fixture: migrations applied, CI running against a real ephemeral Postgres service container on every push, and `fetchWorkspace()` resolving a real ingested workspace when one exists. Real PDF ingest end to end (`scripts/parse.py`, `lib/agents/orchestrator.ts`, `lib/services/ingest.ts`) -- authors/publication year/archetype are now extracted and persisted onto each paper, not just title; a scanned/image-only PDF fails the job with a clear diagnosis instead of silently producing an empty paper; the parsed PDF itself is stored and served back for the reader's real page view instead of a styled mock. Real username/password accounts (Supabase-backed, a required real email so password recovery and email confirmation have somewhere to go, both actually wired now), on top of the existing Google sign-in -- sessions are server-side revocable (logout kills that one session; "sign out everywhere" kills every session for the account). Node body edits now re-verify every citation against the edited text and record version history; deleting a node cascades correctly. Cross-paper synthesis (`lib/services/synthesis.ts`, `POST /api/compare`) writes real `agrees`/`contradicts`/`extends`/`shares_method`/`relates` edges and 4 of `docs/PLAN-V1.md` §10's 6 synthesis node types (Consensus, Contradictions, Timeline of Findings, Methodological Divergence). Export (`GET /api/export`) and promote-to-thread (`POST /api/chat/promote`) are both real. Every workspace-scoped mutation route now requires a session for anything other than the public demo workspace, and an unrecognized workspace id 404s instead of silently serving the demo fixture. The four reader subpages (Audit/Outline/Learn/Canvas) share one navigation shell, spacing scale, and guest banner instead of four independently drifted headers.

`equations` and `figures` (`lib/agents/generators/`) are now real too, closing the last two node generators that needed real extraction work rather than a prompt. `scripts/parse.py`'s PyMuPDF pass now also runs Pix2Text (free, open-source, fully local -- no deployed Python service, per the cut list) per page: it detects display-equation regions and converts them to LaTeX for `equations`, and for `figures` it crops each detected figure region to a PNG and pairs it with its nearest real caption (matched by a `Figure N`/`Fig. N` prefix), producing a real `figure_caption`-kind chunk with real anchorable text -- a figure Pix2Text couldn't match a caption for is dropped rather than given a chunk with nothing to verify. `figures` needed a third model tier since neither of the existing two providers can serve an image-input call at all: `visionModel()` in `lib/ai/client.ts` resolves to OpenRouter (openrouter.ai, free signup, no card), specifically a free `:free`-suffixed model, verified live with a real authenticated multimodal completion at `cost: 0`. Two defensive fixes came out of testing this against a real academic PDF, not just the fixture: `lib/services/pythonRunner.ts` now trusts a complete, valid JSON stdout payload over an incidental non-zero exit code (Pix2Text's onnxruntime/CoreML teardown crashes on some machines after stdout is already fully written), and `lib/services/verify.ts` recovers a citation the model wrote as a bare `[C7]` instead of the instructed notional `[^n0]` marker -- both observed live from the free vision model, same "a prompt is a request, not a guarantee" class already established elsewhere in this codebase.

## [0.1.1] - 2026-08-15

### Added

- **Google sign-in, and the reader opened to guests.** `/w` and `/upload` were in the middleware's protected list, so a first-time visitor could not read a paper or add one without an account. Sign-in now buys persistence rather than access; the account-shaped routes stay protected because they are meaningless without an identity. Guest surfaces carry a banner naming the actual consequence ("papers you add and questions you ask disappear when you close this tab") rather than an upsell, which is what makes open access honest instead of a trap. Google goes through Supabase as the OAuth broker so the client secret lives in Supabase's config, and the flow starts browser-side because PKCE needs the code verifier written before the browser leaves for Google. The callback translates the Google identity into the app's own signed cookie rather than carrying a Supabase session alongside it -- two session mechanisms would mean two answers to "who is signed in" -- with federated profiles riding inline in that HMAC-signed cookie, since a Google account has no row in the seed adapter and an id-only cookie would authenticate to a profile that cannot be resolved.
- **A key for the graph (`components/canvas/CanvasLegend.tsx`).** The canvas draws 5 card types, 7 pillar hues and 8 edge kinds across 3 dash patterns, every one decided in a component and explained nowhere; the only hint was a label that appears when you hover one specific edge, which cannot tell you a legend exists. Closed by default, and lists only what the current workspace actually draws. Meanings live in `lib/graph/legend.ts` so the key cannot drift from the picture, with a test that every schema edge kind is explained -- a legend that silently omits one reads as complete and is worse than none.
- **Zoom level-of-detail (`lib/graph/lod.ts`).** Cards rendered full body text at every zoom, including 0.2x where 12px type is about six pixels tall. Bodies drop below 0.75 and titles below 0.45, so a zoomed-out graph reads as shape rather than a wall of grey rectangles. Applied as one attribute on an ancestor rather than a prop per node, so crossing a threshold costs an attribute change instead of rebuilding every node object.
- **Canvas chrome.** That route has no layout of its own, so it filled the viewport with no title and no exit -- browser back was the only way out, and a reader arriving by link had none.
- **`/how-to-use`**, a practical guide in the order you would actually do things. `/how-it-works` argues why the verification is deterministic, for someone deciding whether to trust this; it does not tell someone who already has what to click.

- **MCP server (`mcp/*`), replacing five TODO comments with a working stdio server** -- verified end to end over the real protocol using the SDK's own client, not just typechecked. 8 of the `docs/PLAN-V1.md` §13.2 tools (`search_paper`, `verify_claim`, `get_outline`, `get_node`, `create_node`, `find_contradictions`, `paper_facts`, `list_papers`), 3 resource templates for `@`-mentioning a workspace/paper/node, and the 4 §13.3 prompts. No `ask` tool, by design: exposing search + verify and letting Claude reason is the better MCP design and the better story -- we supply ground truth, Claude supplies inference.
  - `create_node` re-verifies every submitted claim through the existing deterministic verifier, so there is deliberately no parameter a client could use to assert `quote_located`. Confirmed by submitting a fabricated quote: the anchor is dropped and the node returns `low_confidence`.
  - Two service files the tools needed. `lib/services/search.ts` scores keyword coverage rather than doing vector search (plan.md §2 killed embeddings) and returns stable `C{n}` ids that `buildRefIndex` can actually resolve, so a citation built from a search hit can never register as a `hallucinated_ref`. `lib/services/nodes.ts` renders the outline as a compact text tree, resolves anchors inline to quote/page/deep link, and filters `find_contradictions` to two-sided pairs -- a contradiction with one dropped anchor is one claim and an assertion, not something to show a reader.
  - `mcp_tokens` could not satisfy §13.4's own "non-negotiable" rules, so the schema now stores a SHA-256 hash instead of the raw token, carries a read/write scope, allows a null `workspaceId` for unpinned tokens, and records `revokedAt` rather than deleting the row.
  - `@modelcontextprotocol/sdk` pinned to the installed 1.30.0 (was `^1.0.4`, where `.tool()`/`.resource()`/`.prompt()` are deprecated in favour of the `register*` API this uses).
- **Deterministic canvas layout (`lib/layout/*`), so the graph works with more than the bundled fixture.** Every node position used to be a hand-authored coordinate in `fixtures/workspace.json`, meaning a fourth paper had nowhere to go. `radial.ts` rings a single paper's pillars at a radius derived from the chord constraint `w/(2·sin(Δθ/2))`, so the ring opens up as pillars are added instead of cramming, and fans leaves across the spec's fixed ±35° with the radius flexing so the fan never self-overlaps. `layered.ts` gives several papers one column each via nested `packRow`, with every row on a shared Y so "methods across all three papers" reads horizontally, and puts synthesis/thread nodes in a real slot of the same top-level `packRow` so the centre gutter is genuinely centred at any paper count. Applied inside `fetchWorkspace()` -- the single data seam -- because the canvas reads through the client store while API and MCP callers read the service directly, so laying out in any one of those would leave the others stale. Verified with no overlapping cards at 1, 2, and 3 papers by trimming the fixture's paper set, which is the check hand-authored coordinates could never pass.
- **A canvas that opens as structure rather than 20 competing cards.** Pillars start collapsed with a chevron and child-count pill (the §9.1 state table for `PillarNode`, specified and never built) -- 20 visible nodes down to 12 on the fixture. Edges render only when both endpoints do, and that one generic rule does all the edge decluttering, since 15 of the fixture's 22 edges are `contains` scaffolding; a contradiction edge correctly disappears while collapsed and returns when both its pillars open. Citation expansion is now per-paper on demand instead of firing for every paper on load. Edge hover thickens the stroke and shows a midpoint kind label (§9.1), with a wide invisible hit path because a 1px bezier is unhittable in practice.
- **Grounded chat (`lib/services/chat.ts`, `POST /api/chat`)**, replacing a UI shell of two hardcoded messages. Full §9.4 pipeline: query rewrite from the last 4 turns (so "what about that one?" reaches retrieval with a referent), route classifier, context block from the existing `buildContextBlock`, answer on the strong tier, then every cited ref re-checked by `verifyClaimsAgainstCorpus` -- an invented ref comes back `unsupported` rather than looking like support. Refusal path says the papers don't cover it and offers an explicit "answer without sources"; ungrounded answers render with an amber left border and a "no sources located" label, never interchangeable with a grounded one. Verified against the live Groq API.
- **Real upload validation (`lib/services/upload.ts`, `POST /api/ingest`)**, replacing a 501 and a UI that faked success with a timer. Limits are exported constants (50MB, 120 pages) shared by the route and the UI instead of numbers hardcoded in two places. Checks run cheapest-first: size before the body is buffered, magic bytes rather than the extension, page-count estimate, text-layer check, then duplicate detection (DOI, then fuzzy title via the same `tokenSetRatio` the grounding spine uses) returned as a 409 the UI can offer merge-or-open-existing on. arXiv `abs`→`pdf` is a pure rewrite; PMC and DOI are classified for later resolution rather than pretending to resolve now. `GET /api/jobs/[id]` streams the 9-stage §6 progress list over SSE with each stage marked done/current/pending, so the UI can show the whole sequence instead of an indeterminate spinner. Every rejection path verified against the running server.

- **Design system: Editorial Paper direction, full token set, and a real `components/ui/` primitive library.** Locks the visual direction on top of the existing "lab notebook at night" thesis (Are.na × Instapaper/NYT Reader; brief and canonical palette in `design/DIRECTIONS.md`), reconciles `app/globals.css`/`tailwind.config.ts` with the complete `docs/PLAN-V1.md` §14.2 token set (spacing, radius, elevation, motion durations/easings, layout dims -- previously color/font only), and wires real webfonts via `next/font` (Source Serif 4, Inter, JetBrains Mono replaced a silent Georgia/system-ui fallback that had been rendering since the tokens were first named). `components/ui/` grows from 4 files to a real primitive library: Button, IconButton, Input/Textarea/FormField, Dialog, Drawer, Tooltip, Popover, Tabs, Menu, Toast/Toaster, Skeleton, ErrorBanner, Badge (PillarChip/RefChip/EvidenceBadge consolidated onto it), Icon (Lucide, first icon library in the app), and Logo. Implements the `docs/PLAN-V1.md` §14.3 motion spec and §14.5 state spec everywhere this app has a real trigger for them: canvas node-appear entrance with sibling stagger, the PDF highlight "money shot" animation, the citation-chip 140ms hover popover, contradiction-edge dash-march, and empty/loading/error states across chat, canvas, the reader, and the related-papers rail. Fixes a real a11y gap `docs/PLAN-V1.md` §15 flagged (3 of the 7 canonical pillar hues fell below WCAG AA's 4.5:1 as text against `--surface-raised`) and adds a global `focus-visible` fallback. Adds `app/icon.svg`, `app/apple-icon.tsx`, and `app/opengraph-image.tsx` (no logo/favicon/OG image existed before), and redesigns the landing page grounding-first per the new `docs/PLAN-V1.md` §22 Platform Vision (accounts, publish/auto-graph, discovery, discussion -- additive scope targeting Aug 17 alongside the existing demo, not built this pass). Also fixes a real bug this work's own browser QA surfaced: ghost-citation node/edge ids collided whenever two workspace papers shared an external citation, silently dropping one of the two real edges (`components/canvas/GraphCanvas.tsx`).
- **The LLM layer now runs on Groq (primary) + Featherless (fallback), not Anthropic.** `ai` bumped 4.x -> 5.x to pair with provider packages sharing the same `@ai-sdk/provider` major (2.x); `@ai-sdk/anthropic`/`@anthropic-ai/sdk` removed. `lib/ai/client.ts` resolves each tier through `lib/ai/fallbackModel.ts`'s `withFallback()`: try Groq, and only on a 401/402/403/429 or provider-marked-retryable error -- something specific to Groq or this account on it -- retry the identical call against Featherless (`@ai-sdk/openai-compatible`, no first-party AI SDK provider for it). ### Fixed

- **`main` did not typecheck or lint.** `class-variance-authority`, `tailwind-merge` and `@radix-ui/react-slot` were in `package.json` but never installed, so `VariantProps` silently resolved to `{}` and every `variant`/`size` prop on the shadcn primitives became a type error: 82 of them. Separately, `.cjs` scripts and `tailwind.config.ts` were linted under `no-require-imports`, a rule neither can satisfy. Both gate CI, so no build on `main` could have been green.
- **The upload form never called the server.** `submit` ran three client-side guards and then set "Validation passed." unconditionally, so a 200MB executable renamed `.pdf` got the same congratulations as a real paper -- the magic-byte, page-cap, text-layer and duplicate checks all existed in `lib/services/upload.ts` and were never reached. A validation message that cannot fail is worse than none: it tells a reader their file is fine when nothing looked at it. It now posts to `/api/ingest` and surfaces the specific rejection verbatim, which is the entire reason those checks are server-side.
- The canvas legend covered three nodes including an entire paper column, and the obvious fix (more uniform `fitView` padding) does not work on a width-constrained graph -- it just scales everything down while the leftmost column still lands underneath. Reserving the panel's real width on the left does. That in turn zoomed a 3-paper graph below the title threshold, so opening the key turned every card into a blank block; `fitView` now floors at the readable band. Both found by opening it in a browser, not by typing.
- Four "Try the demo" links (hero, landing page, how-it-works CTA, footer) still routed through `/login?next=...`, asking for credentials the reader no longer needs.
- `initialsFor` split the whole email address, so `alex@example.com` read as "AE" -- the domain's initial rather than the person's. Caught by writing its test.

- **Groq's gpt-oss models cite with CJK fullwidth brackets (`【C2】`), not the ASCII `[C2]` the prompt asks for** -- caught by a live API call, invisible to unit tests written against the prompt's own assumptions. The ASCII-only regex parsed those to zero citations, so a correctly-grounded chat answer came back reporting itself as **ungrounded with no sources**, which is the worst failure this product has: it makes sourced output look unsourced. Bracket handling now lives in `lib/chat/citations.ts`, shared by the server pipeline and the client renderer so the two cannot drift, with the fullwidth case pinned by test.
- A generator is instructed to cite a context-block id as the bare token ("C7"), not the full bracketed header ("C7 | Methods | p.4") -- observed a real model return the full header live anyway, despite the prompt. `lib/agents/orchestrator.ts`'s `normalizeRef()` now strips to the leading token before verification regardless of what came back, so this doesn't silently register every affected claim as `hallucinated_ref`.
- The ghost-citation node's "Add to workspace" button POSTed to `/api/expand` and always came back 501, because promoting a ghost needs the parse pipeline. Honestly reporting a 501 is the right pattern for an endpoint that might work; a control that can *never* succeed is just a broken button, so it now links to the paper on OpenAlex and returns when there is something for it to call.
- `classifyExternalError` only treated HTTP 429 as rate-limited. OpenAlex's anonymous-search tier returns a plain `503` with `Retry-After` when its search cluster is overloaded rather than quota-limiting a specific caller -- observed directly against the live API while building `citationExpand.ts`. Both now classify as `rate_limited`, so the UI gives the same "try again shortly" message either way instead of a generic error.
- A claim asserting a bound (`p < 0.05`) against a source reporting a value inside it (`p = 0.003`) was demoted to `unsupported`. `numericTokenMatchesRow` compared values for equality and ignored the comparator it had already parsed, so exact quotes failed the entailment floor on the phrasing most common in the target corpus.
- Citation ids were assigned from array position, so ingesting a paper renumbered every `C{n}` and silently re-pointed already-written `evidence` rows at different text. They now come from a persisted `ordinal` assigned once at ingest.
- The reverse audit scored every (sentence, chunk) pair with a full Levenshtein pass over whole chunk texts. Imperceptible against the 18KB fixture, minutes against a real corpus. Now pruned with an admissible length-ratio bound, which returns the same best chunk: a 10-sentence audit over 300 realistic chunks went from ~10.3s to ~0.5s.
- `app/api/audit` reached into `lib/grounding/*` directly, breaking the service-layer boundary CLAUDE.md defines. Added `lib/services/audit.ts`.
- Server routes imported `fetchWorkspace` from the client zustand store, pulling a client-state container and the whole fixture into the server bundle. The read moved to `lib/services/workspace.ts`; `lib/store/workspace.ts` re-exports it for client consumers.
- `PaperArchetype` in the frozen `types/anchor.ts` contract listed six archetypes; `lib/agents/archetypeClassifier.ts` specified a different nine. Reconciled on the classifier's set, and the fixture's papers remapped (`meta_analysis` to `systematic_review`, `observational` to `cohort_study`).

## [0.1.0] - 2026-08-05

### Added

- Grounding spine (`lib/grounding/*`): deterministic fuzzy-match quote verification (`token_set_ratio`, no LLM judge), the numeric entailment overlap floor, and citation-ref resolution.
- Data layer: full Drizzle schema across all 18 tables in the plan.md §5 data model, Supabase browser/server/service clients, `drizzle.config.ts`.
- Shared contract: `types/anchor.ts` and a worked `fixtures/workspace.json` (3 papers, a contradiction pair, a cross-paper cites link, and one planted misattribution that the verifier correctly demotes to `unsupported`).
- Full UI: React Flow canvas (5 node types + ghost citation nodes + kind-colored edges), the doc-reader view (default landing surface), outline/audit/learn/canvas/share pages, chat dock, node inspector, flashcards/quiz, numeric charts — all against the "lab notebook at night" dark-first design tokens.
- Real API routes: `POST /api/verify` (single-claim re-verification), `POST /api/audit` (reverse audit — paste external text, sentence-split, verify each sentence against the corpus), `GET /api/graph/[workspaceId]`.
- Placeholder `501` handlers for the remaining `app/api/*` routes that need LLM/job-queue/live-DB infra not yet provisioned, so the app builds cleanly end to end.
- Project documentation: README, CLAUDE.md, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, LICENSE (MIT).

### Fixed

- Entailment-floor check was scoped to a single `Numeric` row instead of every numeric belonging to the resolved chunk — caught via a sanity check against the fixture and fixed before it shipped.
- A `"95% CI ..."` confidence-interval annotation was being treated as its own claimed statistic, causing false `unsupported` verdicts on otherwise-exact quotes; the numeric-token extractor now excludes it.
